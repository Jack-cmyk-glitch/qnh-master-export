# 排障

## 返回成功但商品数为 0

平台可能对空租户、受限账号或异常会话都返回 `code:0, list:[], total:0`。
程序退出 3，不生成成功导出；这不是权限根因的充分证据。
在平台商品页检查数据是否可见，并确认是正确的租户与账号。

## 找不到页面或无法绑定

1. 自己在 Chrome/Chromium 中登录并打开牵牛花 `home.html` 商品页。
2. 关闭该标签页的 DevTools（会与扩展 debugger 连接冲突）。
3. 运行 `opencli doctor`。
4. 多连接环境用 `qnh-master clients` 选择目标 `--client`。
5. 运行 `qnh-master doctor` 验证绑定；它只验证域名，不读取商品权限。

程序不打开独立浏览器 profile，不导航到新的账号，也不读取或导出 Cookie。
上游单连接 daemon 没有 `/clients` 时，程序通过 `/status` 识别 default 连接。

## 超时、HTTP 429 或风控

超时后停止本次采集，避免原请求尚未结束时重试造成叠加请求。
确认页面恢复、原请求已结束后再续采；如出现验证，按平台正常流程处理。
保持串行并增大 `--gap`，不要并发突发、修改签名或绕过验证。
浏览器页面同步阻塞时，JavaScript 定时器未必能按时触发；本机 HTTP 客户端还有独立超时。

## 混租户、缺页、总量变化、重复 SPU

程序逐页校验，不把失败页标记为已完成。
如果总量/首页内容变化或出现重复 SPU，使用新目录重新采集。
账号可见总数不一定代表租户全量；通过页面和账号权限配置核对可见范围。

## 续采文件损坏或锁定

`.pages/` 原始页文件与 manifest 中的 SHA-256 必须一致。
不要手改页文件或 checkpoint；损坏时保留现场并用新目录重采。
出现 `.collect.lock` 时，先确认原进程已经结束，再手动移除锁文件。

## 分享问题时

提供 Python / OpenCLI 版本、使用的子命令和简短错误即可。
替换账号参数，不上传完整 daemon `/clients` 响应、Cookie、请求头、真实商品记录或原始日志。
